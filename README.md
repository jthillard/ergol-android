# Ergo'L external keyboard

Android app (4.1+) providing an external keyboard layout for Ergo'L.

# Usage

1. Settings -> System -> Keyboard.
2. Plug in the external keyboard.
3. Click on Physical Keyboard -> then the physical keyboard that should have been detected.
4. Click on your virtual keyboard and its language.
5. Choose the "French (Ergo'L)" layout
